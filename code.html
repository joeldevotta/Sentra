How Sentra Works

A four-stage contextual defense system designed to intercept cognitive deception before funds move.

01 INGESTION

DETECT

Analyzes raw pre-payment contextual signals: transaction volume relative to history, handle novelty, coercive psychological triggers, and unverified verification links.

• VPA Age & Novelty
• Pressure Pattern Lexicon
• URL Domain Entropy
02 TRANSPARENCY

EXPLAIN

Eliminates the black-box effect. Breaks the compound score down into auditable contributing points (+25 Urgency, +20 Amount, +20 URL) so the user comprehends the exact vulnerability.

• Additive Points Audit
• Plain-Language Evidence
• Context Discrepancy Note
03 INTERVENTION

PROTECT

Injects a tactile Liquid Glass circuit-breaker into the transaction sequence. Breaks the fraudster's psychological urgency loop before irreversible payment dispatch.

• Tactile Circuit Breaker
• Out-of-band Verification
• De-escalation Delay
04 SOVEREIGNTY

DECIDE

Empowers the user with sovereign decision-making. Sentra does not take custody of funds, freeze bank accounts, or block users against their informed will.

• User Autonomy Preserved
• Verified Proceed Override
• Zero Asset Custody
PRIVACY BY HARDWARE DESIGN

Protection without surveillance.

The core philosophy of Sentra is: “Make the risk visible, not the user exposed.”

NO BANKING PASSWORDS

Sentra never asks for or stores internet banking passwords, CVVs, or debit/credit card numbers.

NO UPI PIN EXPOSURE

Your UPI PIN is entered exclusively on NPCI-certified terminal screens. Sentra has no keyboard hook or access to PIN inputs.

VOLUNTARY CONTEXT ONLY

Only the non-sensitive metadata (amount, recipient handle, notes) provided during inspection is evaluated.

NO HIDDEN DECISION MAKING

Every calculation is fully inspectable on-screen, preventing arbitrary AI hallucination or silent fund refusal.

Architecture Note: SENTRA is an explainable pre-payment fraud detection and protection layer. It is NOT a bank, UPI payment app, escrow agent, or financial custodian. This prototype is engineered with modular decoupled logic ready to interface with banking APIs and browser security extensions.
